# Topics Studied

## Vulnerability Disclosure Process

A software vulnerability typically follows these stages:

1. Vulnerability Discovery
2. Responsible Disclosure
3. CVE Assignment
4. Publication in the National Vulnerability Database (NVD)

This process ensures vulnerabilities are documented consistently and can be referenced by the global cybersecurity community.

---

## National Vulnerability Database (NVD)

The National Vulnerability Database is a publicly accessible repository maintained by the National Institute of Standards and Technology (NIST). It stores enriched information about publicly disclosed vulnerabilities, including severity scores, software weaknesses, affected products, and references.

---

## Difference Between CVE and NVD

A CVE (Common Vulnerabilities and Exposures) is a unique identifier assigned to a vulnerability.

The NVD is the database that stores detailed information about each CVE.

---

## Information Stored in an NVD Record

Each vulnerability record may include:

- CVE Identifier
- Description
- CVSS Score
- CWE
- Affected Products
- References
- Vendor Information

---

## JSON (JavaScript Object Notation)

The NVD publishes vulnerability information in JSON format.

JSON is a lightweight data-interchange format that stores information using key-value pairs. It allows applications to exchange structured data efficiently.

---

# How This Relates to the Project

The AI Threat Intelligence Assistant will retrieve vulnerability information from the National Vulnerability Database, process the JSON data, store it in a database, and send the relevant information to an AI model for summarization, MITRE ATT&CK mapping, and mitigation recommendation generation.

---

# Key Learnings

- The NVD is the primary public source of vulnerability information.
- A CVE identifies a vulnerability, while the NVD provides detailed information about it.
- Vulnerability information is exchanged in JSON format.
- The AI assistant will use NVD data as its primary intelligence source.
